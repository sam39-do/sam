# 星原沙盒

一个可离线游玩的 HTML Canvas 2D 沙盒小游戏，已经接到仓库首页 `index.html`。

## 玩法

- 挖掘草方块、泥土、石头、树木、沙子和晶矿。
- 使用背包资源放置方块，搭建小基地。
- 合成木板和灯，在夜晚照亮自己的建筑。
- 种下树苗后会慢慢长成新树。
- 世界会自动保存在浏览器本地，也可以手动保存。
- 可切换创造模式，快速建造和测试布局。

## 操作

- 移动：`A` / `D` 或方向键
- 跳跃：`W` / `Space` / 上方向键
- 数字 `1-8`：切换工具栏
- `E`：切换到下一个工具
- 左键：用当前工具挖掘或放置
- 右键 / `Shift` + 左键：挖掘
- `F`：对准光标位置使用当前工具

## 本地运行

直接打开 `index.html` 可以离线游玩。也可以启动本地预览服务：

```bash
npm start
```

然后打开：

```text
http://127.0.0.1:5173
```

## 文件

- `index.html`：主页结构和游戏界面
- `styles.css`：沙盒游戏界面样式
- `sandbox.js`：世界生成、物理、挖掘、建造、背包、保存等核心逻辑
- `server.mjs`：本地静态预览服务
- `game.js`：旧版横版冒险游戏脚本，当前主页未引用
