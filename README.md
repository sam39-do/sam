# 小熊大冒险

一个本地离线可玩的 HTML Canvas 横版平台小游戏。主角是 Q 版小熊，包含关卡选择、道具商店、皮肤、羽毛球拍武器、三段跳、护盾、池塘、Boss、机甲 Boss、炮台和暴击系统。

## 运行

直接双击 `index.html` 就可以离线游玩，不需要网络。

如果想用本地服务预览，也可以运行：

```bash
node server.mjs
```

然后打开：

```text
http://127.0.0.1:5173
```

## 本次画质与平衡更新

- 画面改为高 DPI 渲染，按设备像素比提升清晰度。
- 增加电影感调色、暗角、光束、远景山体、地面阴影和颗粒效果。
- 游戏文件只引用本地 `index.html`、`styles.css`、`game.js` 和本地素材，可无网络游玩。
- 暴击从原来的超夸张秒杀型伤害改为更可控的高额伤害池，保留爽感但减少一刀破坏关卡节奏。
- 羽毛球命中伤害从五分之一调整为约六分之一，压迫感战力持续时间和冷却重新平衡。
- 压迫感不再自动清空所有强敌血量，而是造成高额爆发伤害，让 Boss 战更有来回。
- 怪物命中主角后的强化时间和无敌时间下调，让难度会上升但仍可通关。
- 新增整体平衡：不删除任何机制，但降低暴击峰值、延长斩杀冷却、限制踩怪回血频率，并让斩杀对 Boss 变成高额斩血而不是直接跳过战斗。
- 小手枪获得后，按 `Q` 可切换为小猪伙伴。小猪会跟在主角后方，并自动锁定附近敌人发动粉色子弹攻击；按 `E` 可让小猪立即尝试攻击一次。
- 商城新增奥运/世锦赛风格羽毛球场背景和柔道场背景，标价均为 1 美刀，作者免费拥有并可切换。商城还新增大转盘：每次 7777 星星，99% 获得皮肤、0.999% 获得 1 个商城货币、0.001% 直接获得背景；重复奖励会转成 1 星星。1 个商城货币可兑换皮肤，10 个商城货币可兑换背景。
- 关卡新增普通原皮小熊怪，数量约为僵尸怪两倍，3 格血，只会用球拍每 10 秒发射三枚普通平抽，命中主角每枚掉 1 格血。所有 Boss 血量提升为原来的 2 倍。
- 商城新增 Victor P9200 TTY 跑鞋，标价和背景一样，作者免费拥有；按 `I` 可穿戴/脱下，穿上后移动速度和挥拍速度提升 50%。
- 所有关卡 Boss 前新增大量机关枪炮台；没穿跑鞋时，主角攻击伤害提升 40%，该加成作为商城作者免费项目，可在商城启用/关闭。
- 所有怪兽和 Boss 对主角造成的伤害整体提高 20%。

## 操作

- 移动：`A` / `D` 或方向键
- 跳跃：`W` / `Space` / 上方向键
- 球拍攻击：鼠标左键
- 手枪射击：`E`
- 手枪 / 小猪伙伴切换：`Q`
- 羽毛球打法切换：`G`
- 触屏设备：使用右下角按钮
