# 九熊山

主页现在是一款古风小熊 3D 生存沙盒游戏。它保留旧版游戏里的武器、商店、小猪伙伴、怪兽与 Boss，同时把核心玩法改成更接近《我的世界》的方块建造、采集、探索和生存。

## 本轮优化

- 主题页名称改为“九熊山”，页面字体改成古风中文字体栈。
- 主角换成“九熊山侠衣”：古代侠义风、山水纹风衣、腰带和披摆。
- `A` 按视角向左移动，`D` 按视角向右移动。
- `L` 新增传送能力：传送到距离主角最近的火山安全点。
- 地图再次扩大 2 倍，当前世界尺寸为 `2880 x 2880`。
- 火山总数固定为 9 座，20 秒喷发一次；喷发、烟灰、熔岩和命中特效进一步加强。
- 火山常态地表改成半红半灰；喷发时出现深红火焰，并会灼烧周围玩家、怪物、掉落物和地表方块。
- 怪物数量大幅增加，普通怪远处休眠以降低卡顿；Boss 增加到多点分布，并加入火山 Boss 与暗影 Boss。
- 主角新增腰部“赤风立体机动装置”：`J` 穿戴，穿戴后球拍自动收回，左键用红色血风格钩爪锁点移动，可连续无限使用。
- 立体机动机制完善：左键可锁方块或巨人身体拉拽移动；右键使用特制刀刃，只对巨人后颈有效。
- 新增调查披风：深绿色，背后为简化双翼徽记，会根据移动速度和风向摆动。
- 鼠标上下方向修正：鼠标前推视角向上，向后拖视角向下。
- 新增巨人系统：普通种无垢巨人、奇行种无垢巨人会群居行动；进击、铠甲、女型、兽、颚、超大型等变身巨人按体型差异生成。
- 帧率优化：自然地形不再全部投影，渲染半径降低，阴影贴图减负，加入动态像素比调节。
- 攻击轨迹、命中特效和拍子挥击反馈加强，仍使用向前挥拍攻击。
- 降低明显延迟：限制粒子总量、降低小地图刷新频率、远距离火山不生成重粒子，远处普通怪暂停追踪。
- 已改为本地 `vendor-three.mjs`，运行游戏不依赖外部 CDN，仓库文件可在无网环境下启动。

## 已保留内容

- 武器：Starter、Auraspeed 100X Ultra、Arcsaber 7 Tour、Nanoflare 700 Game、Anta Dingyin 1000。
- 商店：皮肤、球拍武器、跑鞋、赤脚强化、Jump Smash、小猪伙伴、徒手冲刺、幸运转盘。
- 对手：僵尸怪、球拍小熊怪、机关枪炮台。
- Boss：Rabbit Boss、Zombie Boss、Gundam Mech Boss、Deep Red Volcano Boss、Shadow Hook Boss。
- 巨人：无垢巨人普通种、无垢巨人奇行种、进击巨人、铠甲巨人、女型巨人、兽之巨人、颚之巨人、超大型巨人。
- 模式：`C` 切换生存/创造；生存模式每 20 秒有 20% 概率触发 12 秒创造能量。
- 方块系统：左键挖掘并收集，右键放置当前方块，数字键切换工具栏。
- 生存机制：最高生命值 100，火山熔岩命中后持续 10 秒灼烧，每秒 0.5 格血。

## 操作

- `WASD`：按当前视角移动
- 鼠标：转视角，前推抬头，后拖低头
- 左键：普通状态攻击或挖掘；穿戴立体机动时使用钩爪
- 右键：普通状态放置当前方块；穿戴立体机动时使用后颈刀刃
- 数字 `1-8`：切换工具栏
- `C`：切换生存/创造
- `Y`：切换第一视角/第三视角
- `J`：穿戴/脱下赤风立体机动装置
- `L`：传送到最近火山
- `Q`：切换球拍和手枪/小猪伙伴模式
- `E`：手枪或小猪伙伴射击
- `G`：切换羽毛球打法提示
- `I`：解锁跑鞋后穿戴/脱下
- `Shift`：冲刺

## 本地运行

```bash
npm start
```

然后打开：

```text
http://127.0.0.1:5173
```

也可以直接部署到 GitHub Pages。`index.html` 会加载 `sandbox.js`，Three.js 已放在本地 `vendor-three.mjs`，避免打开主页时依赖外部模块。

## 文件

- `index.html`：九熊山主页和 HUD 结构
- `styles.css`：古风界面、HUD、商店、背包和工具栏样式
- `sandbox.js`：Three.js 3D 生存沙盒、建造、采集、武器、商店、怪兽、Boss、火山和传送逻辑
- `vendor-three.mjs`：本地 Three.js 模块
- `game.js`：旧版 2D 游戏脚本，保留作参考
- `server.mjs`：本地静态预览服务
